# NEW STATE CITY LAUNCHER

مشروع لانشر Android مخصص لسيرفر NEW STATE CITY، مستوحى من فكرة لانشرات SA-MP المحمولة.

## الخطة
- واجهة عربية بهوية سوداء وزرقاء وسماوية.
- شاشة رئيسية تعرض حالة السيرفر وزر اللعب.
- إدارة عنوان السيرفر والمنفذ من الإعدادات.
- صفحات الأخبار والإعدادات.
- دعم تكامل عميل SA-MP بعد التحقق من طريقة تشغيله على جهاز Android المستهدف.

## الحالة الحالية
هذا مستودع تأسيسي. لم يتم بعد تضمين عميل اللعبة أو ملفاتها أو إعدادات اتصال حقيقية، ولم يتم بناء APK أو اختباره.

## الإعداد
انسخ `.env.example` إلى `.env` ثم املأ القيم بعد تجهيز بيانات السيرفر والاستضافة.

## ملاحظة مهمة
هذا المشروع مستقل ولم تُنسخ فيه ملفات المصدر من مستودع طرف ثالث. يلزم التحقق من ترخيص وأذونات أي كود أو أصول خارجية قبل إعادة استخدامها.
